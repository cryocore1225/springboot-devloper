Blogsystem backend

博客系统后端：文章（含草稿/发布）、标签、评论、站内成员，数据存放在 H2 内存数据库里。

所有资源接口都在 /api 下。浏览器只能直接访问 GET 接口， 新增/修改/删除请用 Postman、curl 或 PowerShell，具体命令见项目 README。

文章

方法地址说明
GET/api/articles分页查询文章，参数 page（从 0 开始）、size、published
GET/api/articles/search?keyword=JPA按标题模糊搜索，忽略大小写
GET/api/articles/{id}按 id 查单篇，查不到返回 404
POST/api/articles新增文章，成功返回 201；标题/正文/作者为空返回 400
PUT/api/articles/{id}整体替换，需要传全部字段
PATCH/api/articles/{id}局部更新，只改传了的字段
POST/api/articles/{id}/publish把草稿发布出去
POST/api/articles/{id}/unpublish撤回成草稿
DELETE/api/articles/{id}删除文章，连同它的评论一起删

评论

方法地址说明
GET/api/articles/{articleId}/comments查某篇文章的全部评论，按时间正序
POST/api/articles/{articleId}/comments发评论，请求体只要 {"author":"...","content":"..."}
GET/api/comments/{id}查单条评论
DELETE/api/comments/{id}删除评论，成功返回 204

站内成员

方法地址说明
GET/api/members查询全部成员
GET/api/members/1按 id 查询
POST/api/members新增成员，邮箱重复返回 409
PUT/api/members/{id}整体替换
PATCH/api/members/{id}局部更新
DELETE/api/members/{id}删除成员，成功返回 204
