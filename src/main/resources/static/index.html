Spring Boot 入门示例

欢迎来到我的第一个 Spring Boot Web 项目。

数据存放在 H2 内存数据库里，下面的成员接口会真正读写数据库。

文本接口

  • /request：@RequestMapping 示例
  • /hi：返回一段问候文本
  • /test：返回另一段测试文本

成员接口

  • GET /members：查询全部成员
  • GET /members/{id}：按 id 查询，例如 /members/1，查不到返回 404
  • POST /members：新增成员，返回 201
  • PUT /members/{id}：整体替换成员信息
  • PATCH /members/{id}：局部更新成员信息
  • DELETE /members/{id}：删除成员，成功返回 204

POST、PUT、PATCH、DELETE 没法直接用浏览器的地址栏访问， 得用 Postman、curl 或 PowerShell 发送请求，具体命令见项目 README。

数据库工具

  • /h2-console：H2 数据库控制台，可以直接执行 SQL 查看表里的数据
